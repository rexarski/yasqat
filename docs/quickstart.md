# Quick start

Ten minutes from a DataFrame to a typology, a set of rules, and a test that
the typology means something. Every line below runs as written on the
synthetic population it builds, and the outputs shown are what it prints.

## 1. Build a pool

```python
import numpy as np
import polars as pl
from yasqat.core import SequencePool
from yasqat.synthetic import generate_markov_sequences

T = np.array([[0.85, 0.10, 0.05], [0.30, 0.55, 0.15], [0.40, 0.10, 0.50]])
df = generate_markov_sequences(
    n_sequences=300, sequence_length=24, transition_matrix=T,
    states=["employed", "unemployed", "training"], seed=42,
)
pool = SequencePool(df)      # with real data: load_csv(...), load_dataframe(...)
pool.describe()
```

```
{'n_sequences': 300, 'n_states': 3, 'states': ['employed', 'training', 'unemployed'],
 'total_observations': 7200, 'min_length': 24, 'max_length': 24, ...}
```

The input is long format, one row per (id, time) with a `state` column.
See [Loading data](guides/loading-data.md) for files, other column names, and
interval-shaped sources.

## 2. Describe it

```python
from yasqat.statistics import state_distribution, transition_rates, longitudinal_entropy

state_distribution(pool)               # employed 65.8 %, unemployed 20.7 %, training 13.5 %
transition_rates(pool, exclude_self=True)
longitudinal_entropy(pool)             # 0.692
```

## 3. Measure distance and cluster

```python
from yasqat.clustering import pam_clustering, pam_range

dm = pool.compute_distances(method="om", indel=1.0)   # 300 × 300 optimal-matching distances
pam_range(dm, k_values=range(2, 6))                    # ASW and R² per k; pick the elbow
result = pam_clustering(dm, n_clusters=3, random_state=0)
result.cluster_sizes()                                 # {0: 93, 1: 84, 2: 123}
```

Read each cluster through its medoid, a real sequence:

```python
for cluster, medoid in enumerate(result.get_medoid_ids()):
    print(cluster, "".join(s[0].upper() for s in pool.get_sequence(medoid)))
```

## 4. Test that the typology explains something

```python
from yasqat.statistics import discrepancy_analysis

discrepancy_analysis(dm, result.labels, n_permutations=99, random_state=0)
# DiscrepancyResult(pseudo_R2=0.2583, pseudo_F=51.7137, p=0.0100)
```

A quarter of the pairwise variation is explained by cluster membership, and
no permutation of the labels did as well.

## 5. Mine what tends to follow what

```python
from yasqat.filters import ContainsStateCriterion, StartsWithCriterion
from yasqat.statistics import association_rules

situation = pool.filter(
    [StartsWithCriterion(states=["unemployed"]), ContainsStateCriterion(states=["training"])]
)
len(situation)                                          # 83
rules = association_rules(situation, min_support=0.3, min_confidence=0.6, max_length=3)
rules.sort("lift", descending=True).head()
```

Each rule is `antecedent ⇒ consequent` with support, confidence, lift,
leverage, and conviction. On this population every lift sits at or just
below 1.0, and that is the correct answer: the sequences were generated by a
Markov chain, which has no memory beyond the current state, so knowing that
`training` occurred earlier adds nothing to the odds of what follows. Real
cohorts are not memoryless, which is what makes the rules worth mining.
[Mining patterns](guides/mining.md) derives every measure on a ten-row
example where the lifts do move.

## 6. Plot with whatever you like

```python
shares = pool.to_state_sequence().state_per_sequence(proportion=True)
colors = pool.alphabet.colors        # one colour per state, for consistent figures
```

`shares` is a polars DataFrame; hand it to matplotlib, altair, or plotly. Every
result in yasqat is a DataFrame or converts to one with `.to_dataframe()`.
